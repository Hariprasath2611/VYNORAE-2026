ABOUT THE HACKATHON

01
[ MISSION PURPOSE ]

About VYNORAE

VYNORAE is a 24-hour national-level hackathon that brings together passionate innovators, developers, designers, and problem solvers to build impactful technology solutions.

Participants collaborate in teams, transform ideas into working prototypes, and present them before industry experts and academic leaders. Whether you're passionate about AI, Web3, Cybersecurity, Healthcare, or Open Innovation, VYNORAE is your platform to innovate.

7. RULES & GUIDELINES

Operational protocols and compliance directives for all registered teams.

01 / TEAM_SIZE

Team Size: 3–4

Teams must consist of 3–4 registered students. Solo participation is not permitted under any circumstances.

02 / HARDWARE

Bring Your Own Laptop

Each team member must bring their own laptop, chargers, extension boxes, college ID card, and personal medication.

03 / CONNECTIVITY

Wi-Fi Provided

JEC will provide Wi-Fi access throughout the event. Backup mobile hotspots are highly recommended for uninterrupted connectivity.

04 / ORIGINALITY

Original Work Only

All code must be written during the 24-hour window. Plagiarism or pre-built projects will result in immediate disqualification.

05 / SUBMISSION

GitHub Submission

Final code must be pushed to a public GitHub repository with a proper README explanation before the code freeze deadline.

06 / PRESENTATION

PPT Required

A standard slide deck (PPT) is required detailing the problem, solution, architecture, and technology stack used.

07 / DEMO_VIDEO

Demo Video Encouraged

A 2-minute video walkthrough demonstrating the working prototype is highly encouraged alongside your final submission.
